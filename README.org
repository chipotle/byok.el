* byok.el

A library for accessing the [[https://byok.io/device][BYOK Device]] from within Emacs.

** Why?

The BYOK device is a neat "digital typewriter," but if you're not using the BYOK Studio software that provides wireless syncing, it can be a little clunky to get files in and out using the device's disk mode. This is especially true for Emacs users, who may be writing in Org Mode: the BYOK doesn't recognize the ~.org~ extension as a text file at all. This library is an attempt at a solution within Emacs.

Note that "out of the box" this is configured to work with a Mac; under Linux or Windows, you'll need to adjust the [[*Options][Options]] for both the mounting path and the unmount/eject command.

** Installation

Download ~byok.el~ and use the ~require~ command in your init file:

#+begin_src emacs-lisp
(require 'byok "/path/to/byok.el")
#+end_src

Alternatively, you can use ~use-package~ with the ~vc:~ option:

#+begin_src emacs-lisp
(use-package byok
  :vc (:url "https://github.com/chipotle/byok.el"))
#+end_src

** Usage

*byok.el* provides a set of interactive functions and a Transient menu to call them, mapped to ~C-c b~ in text modes. Before using any functions, you need to put the BYOK into Disk Mode and connect it to your computer.

The *byok.el* library treats the directory name of your current file as the name of a "Project" on the BYOK device. If you're editing ~$HOME/Documents/Stories/Dark and Stormy Night.org~, the project name is ~Stories~. The BYOK requires all files to be in projects.

Use ~C-c b~ in a text mode to call up the BYOK menu:

| Key | Function                              |
|-----+---------------------------------------|
| t   | Copy file from Emacs to BYOK          |
| f   | Copy file from BYOK to Emacs          |
| d   | Ediff BYOK and Emacs file versions    |
|-----+---------------------------------------|
| s   | Copy subtree from Emacs to BYOK       |
| r   | Copy subtree from BYOK to Emacs       |
| e   | Ediff BYOK and Emacs subtree versions |
|-----+---------------------------------------|
| p   | Open BYOK Projects directory          |
| u   | Umount/eject BYOK                     |

Alternatively, call the functions directly (e.g., ~M-x byok-copy-file-to-device~).

*** Example workflow

I'm currently working on a novel, which I'm writing in one big Org Mode file, creatively called ~book.org~. I'm storing it on a path similar to this:

#+begin_example
Documents/
└── Bancroft/
    ├── book.org
    └── notes.org
#+end_example

Every chapter simply begins with its own Level 1 heading (e.g., ~* Chapter 1~, ~* Chapter 2~, etc.). To take a chapter with me on the BYOK, I make sure that point is somewhere inside the chapter I want, put the BYOK in Disk Mode, and plug it in. I press ~C-c b s~ (copy subtree from Emacs to BYOK). Then, I eject it with ~C-c b u~; this should take the BYOK out of Disk Mode.

In this case, if I were in Chapter 21 of the book, then ~Chapter 21.txt~ would be created or updated on the BYOK in the project ~Bancroft~.

When I want to bring changes back into the Emacs file, it's simply the reverse: when point is in the chapter I want to import from the BYOK, I use ~C-c b r~ (copy subtree from BYOK to Emacs; the "r" is for "retrieve," since there wasn't any more obvious letter).

*** What if you start writing a file on the BYOK?

If a file exists on the BYOK that isn't in Emacs, then you can do one of two things:

+ Visit a file whose file name and parent directory match the project name and file name on the BYOK, and use ~C-c b f~. If you want to put it in a subtree, the parent directory has to match the project name and the current /heading/ has to match the BYOK file name. (For instance, I could start a ~Chapter 23~ on the BYOK, then type ~* Chapter 23~ as a heading in the book file in the example above to import it.)
+ Open the BYOK Project directory with ~C-c b p~ and just copy the file wherever you want it.

** Functions provided

*** byok-copy-file-to-device (t)

Copy the current file to the BYOK. The file will always be given the extension ~.txt~ when saved to the BYOK.

*** byok-copy-file-from-device (f)

The reverse of the previous command: copy the file that matches your buffer's current file name (sans extension) and directory/project from the BYOK back to Emacs. This loads the content of the BYOK's file into your current buffer, but doesn't change the file on disk, although it does save the buffer before copying.

*** byok-diff-files (d)

Compare the two copies of the current file using Ediff.

*** byok-copy-subtree-to-device (s)

Copy the current subtree to the BYOK, using the heading of the subtree as the filename: if the subtree's heading is "Chapter 12", the file will be ~Chapter 12.txt~. The project name will be the directory of the current file, as always. This is useful if you're keeping a long document all in one file. Emacs can handle that, but the BYOK can't.

Characters that are not appropriate for a filename will be stripped: the heading ~Musty, or battle-tested?~ will produce the filename ~Musty or battle-tested.txt~ (no comma or question-mark).

Note that a "subtree" is everything from the heading point is on or under down to the next heading at the same level. That is, if point is under an ~H2~ level heading, the subtree includes that heading and all text under it down to (but not including) the next ~H2~ level.

*** byok-copy-subtree-from-device (r)

The reverse of the previous command: copy the file that matches your buffer's current subtree heading name and directory/project from the BYOK back to Emacs. This will replace the buffer's copy of the subtree with the BYOK file, but doesn't change your system's file on disk (although it does save the buffer before copying).

Note that this uses the name of the /file on the BYOK/ for matching. If you change the heading text on your computer before running this, or change the name of the file on the device, the command won't be able to match the file to the heading.

*** byok-diff-subtrees (e)

Compare the current subtree with the corresponding file on the BYOK using Ediff. This command narrows your current buffer to the subtree for the comparison.

*** byok-projects-directory (p)

Opens the BYOK ~Projects~ directory in Dired.

*** byok-unmount (u)

Unmounts or ejects the BYOK device.

** Options

You can customize options in the BYOK group: the path the BYOK mounts on, the command used to unmount/eject the BYOK, and whether to make explicit backups when copying to and from the BYOK. Note that backups stored on the BYOK are not accessible on the device itself, but can be read from the Projects directory when the device is mounted.

*Warning!* The eject command and the mount path are correct for macOS, but will need to be changed for other operating systems.

** Notes

The BYOK device does not keep track of date and time, which makes it impossible for the library to determine whether the file on your device is newer or older than the device on your system. This is why you explicitly copy to or from the device rather than syncing. If you want to get down and dirty with ~ediff~ for changes, you can open the files side by side.

While the file copying commands can work on any text file, the subtree commands require an Org or Markdown file. The latter assumes you're using [[https://jblevins.org/projects/markdown-mode/][Markdown Mode for Emacs]] and probably won't work correctly with other Markdown modes.
